Add to your LLM

Use the endpoint above and the token you created. Replace amcp_... with your actual token, and 127.0.0.1 with this server's address for remote clients. 

claude mcp add --transport http assetmanager http://127.0.0.1:{{ gateway_port }}/mcp --header "Authorization: Bearer amcp_..."
codex mcp add-json assetmanager '{"type":"http","url":"http://127.0.0.1:{{ gateway_port }}/mcp","headers":{"Authorization":"Bearer amcp_..."}}'
hermes mcp add assetmanager --url http://127.0.0.1:{{ gateway_port }}/mcp --auth header
# then add the header to ~/.hermes/config.yaml under mcp.servers.assetmanager:
#   headers:
#     Authorization: "Bearer amcp_..."
// claude_desktop_config.json
{
  "mcpServers": {
    "assetmanager": {
      "url": "http://127.0.0.1:{{ gateway_port }}/mcp",
      "headers": { "Authorization": "Bearer amcp_..." }
    }
  }
}

Any other client (Cursor, VS Code, etc.): add an MCP server of type HTTP, point it at http://127.0.0.1:{{ gateway_port }}/mcp, and set the header Authorization: Bearer amcp_....
