Add to your LLM

Your token is like a password that lets the AI into this inventory — it was sent to you by email when access was granted (admins also see it once, above, when they create it). Below, amcp_... stands for your token: replace it with the real one. If your AI app runs on another computer, also replace 127.0.0.1 with this server's address.

Open a terminal, run this one command, then restart Claude Code:

claude mcp add --transport http assetmanager http://127.0.0.1:{{ gateway_port }}/mcp --header "Authorization: Bearer amcp_..."

Open a terminal, run this one command, then restart Codex:

codex mcp add-json assetmanager '{"type":"http","url":"http://127.0.0.1:{{ gateway_port }}/mcp","headers":{"Authorization":"Bearer amcp_..."}}'

Step 1 — open a terminal and run this one command:

hermes mcp add assetmanager --url http://127.0.0.1:{{ gateway_port }}/mcp --auth header

Step 2 — open Hermes's settings file, ~/.hermes/config.yaml, in any text editor. The command above created an assetmanager entry under the mcp_servers: section. Add your token under it so it looks like this:

assetmanager:
  url: http://127.0.0.1:{{ gateway_port }}/mcp
  headers:
    Authorization: "Bearer amcp_..."

Step 3 — save the file and start a new Hermes chat. To check it connected, run: hermes mcp test assetmanager

Open Claude Desktop → Settings → Developer → Edit Config, paste this block into the file, then restart Claude Desktop:

// claude_desktop_config.json
{
  "mcpServers": {
    "assetmanager": {
      "url": "http://127.0.0.1:{{ gateway_port }}/mcp",
      "headers": { "Authorization": "Bearer amcp_..." }
    }
  }
}

Any other client (Cursor, VS Code, etc.): add an MCP server of type HTTP, point it at http://127.0.0.1:{{ gateway_port }}/mcp, and give it the header Authorization: Bearer amcp_... (your token).
