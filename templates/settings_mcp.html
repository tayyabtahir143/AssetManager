Connect an LLM client (optional)

Only needed if you want an AI assistant (Claude Desktop, Codex, Hermes, Cursor) to query this app. Regular users of AssetManager don't need to run anything here — the app works fully without it. mcp_server.py ships with the app (repo root, and inside the Docker image). Run it once on the machine where your LLM client lives, using the token you created above: 

export ASSET_MANAGER_URL=http://127.0.0.1:5000
export ASSET_MANAGER_TOKEN=amcp_...
python mcp_server.py                                  # stdio
python mcp_server.py --transport streamable-http --port 8765   # HTTP: /mcp
